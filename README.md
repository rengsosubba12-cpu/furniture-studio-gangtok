# 🛋️ Furniture Studio Gangtok

A custom, responsive web application built for Furniture Studio in Gangtok, featuring a sleek modern layout, interactive catalog views, and smooth deployment integrations.

---

## ✨ Features

* **Interactive Catalog:** Clean, modern interface showcasing furniture collections.
* **Responsive Design:** Optimized layout for both mobile and desktop screens.
* **Fast Performance:** Bundled and optimized using Vite for rapid load times.

---

## 🛠️ Tech Stack

* **Frontend:** JavaScript, CSS, HTML
* **Build Tool:** Vite
* **Hosting / Deployment:** Vercel / GitHub Pages

---

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/rengsosubba12-cpu/furniture-studio-gangtok.git](https://github.com/rengsosubba12-cpu/furniture-studio-gangtok.git)
Navigate into the directory:

Bash
cd furniture-studio-gangtok
Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
